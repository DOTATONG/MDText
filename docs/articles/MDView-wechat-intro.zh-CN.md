# 给 Markdown 一个好读的家：我为什么做了 MDView

<!-- 开篇为示意插图；下文标注“实机截图”的配图均由 Windows 版 MDView 现场拍摄。功能说明依据工程当前 v3.4.3 实现；同类软件对比依据文中链接的官方介绍。 -->

有时候，我会把 AI 生成的一份长方案存成 Markdown。内容倒是齐全，打开以后，标题、表格、代码和流程图全挤在一起。想回头找一句话，又得开始翻。

我做 MDView，就是想让这些文档有个舒服的阅读位置：打开就能看，长文有目录，图表和公式能直接显示；发现哪里需要改，也能顺手处理，最后再导出给别人。

项目说明、学习笔记、会议材料也一样。文件还是普通的 Markdown，留在你自己的文件夹里。接下来，我拿工程里的 README 和一份演示稿，带你看看它具体能帮上哪些忙。

![从密密麻麻的文档到清晰易读的页面：文章示意插图](assets/mdview-reading-illustration.png)

*示意插图：把长文整理成更轻松的阅读体验。*

## 打开一份文档，就从这里开始

欢迎页可以打开本地 Markdown、新建文档，或者继续读最近打开的文件。最近文件会显示名称和所在文件夹，碰到两份都叫“方案.md”的文档，也能分清是哪一份。

在 Windows 上，安装版可以关联 `.md` 和 `.markdown` 文件，双击就能打开。喜欢绿色软件，也可以用解压后运行的 ZIP 版。界面支持中文和英文，日常阅读、编辑本地文档不需要注册账号，也不用先把文件上传。

我喜欢这种简单的开始：拿到文档，打开，接着读。

## 长文的目录，可以按你想看的范围展开

左边的目录会根据标题自动生成，点一下就能跳到对应章节；正文往下读时，目录也会标出当前位置。读几十页的方案，先看看章节结构，再挑重点，通常比一直滚轮省事。

目录里还有几个容易被忽略的小操作。你可以选择显示到哪一级标题：先看一级、二级标题了解全貌，要读细节再展开更深的层级。也可以全部展开或收起；双击有下级标题的章节，能单独收起这一支，右键还能展开或收起它的全部子章节。

比如一份方案里既有“预算”又有“实施步骤”，我只想先看预算，就把别的部分收起来。目录面板可以拖宽，标题长一点也好读；想专心看正文，直接收起整个面板就行。

![实机截图：MDView 打开工程 README.md，左侧目录和排版后的正文一同显示](assets/01-reading-outline.jpg)

*实机截图：目录帮你看结构、跳章节，也会提示当前读到的位置。*

如果只记得一句话里的关键词，按 `Ctrl+F` 就能在排版后的预览中查找。匹配内容会高亮，查找栏显示当前位置和总数，还能逐个跳过去。找章节用目录，找一个名字或金额用查找，各有顺手的地方。

## 好读这件事，也包括记得你的习惯

阅读设置里可以选浅色、深色，或者跟随系统。字体有无衬线、衬线和等宽几种选择；Windows 和 macOS 桌面版还可以搜索电脑里已经安装的字体，用自己看着舒服的那一款。

字号、行距和正文宽度也能分别调整。大屏幕上读中文长段落，我会把正文收窄一点；看内容较多的表格，则会留宽一些。调整后直接看效果，想重新开始也有“恢复默认设置”。在 Windows 预览区域，按住 `Ctrl` 滚动鼠标滚轮，还能快速缩放。

这些调整只改变阅读外观。文档里的文字和 Markdown 写法照旧，发给别人时也不用担心把自己的字体偏好带进去。

更省心的是，同一份本地文档再次打开时，MDView 会恢复阅读位置、缩放比例、视图模式，以及目录面板的宽度和开关状态。昨天读到一半的材料，今天可以接着看。

## 代码、图表、公式，还有那些小色块

Markdown 里常见的表格、引用、任务列表和代码块，都能直接看排版结果。宽表格可以横向滚动，列多的时候不用把整篇正文撑开。代码块会显示语言名称和语法颜色，右上角还有复制按钮，拿走一段命令或配置时，省去拖选整块文字的麻烦。

AI 写方案时，经常顺便给出 Mermaid 图表，也就是用文字描述的流程图、时序图等。MDView 能把这些描述画出来；行内公式和独立公式块也能直接显示。一个步骤接到哪里、一个分式的上下项是什么，看图和排版通常更清楚。

![实机截图：行内与块级公式、Mermaid 流程图、表格和代码块](assets/03-rich-markdown.jpg)

*实机截图：公式、流程图、表格和代码放在同一篇文档里，直接读结果。*

我还给颜色值加了小预览。比如一份设计方案写着 `#0F8F83`，支持的十六进制颜色值旁边会出现对应色块。拿着配色表讨论“这个绿是不是太深”，终于有东西可以直接看了。

文档里的本地图片可以按相对路径显示，图片说明会放在下方；点一下图片，能打开大图，查看截图里的小字，看完按 `Esc` 回到正文。文档里用可折叠内容放了补充说明，也可以展开再读。

本地 Markdown 链接可以在 MDView 里继续打开，带章节定位的链接还能跳到指定部分；网页链接交给默认浏览器。读项目 README，再点进相关说明，就能顺着文档自己的线索往下看。

## 读到一半想改几句，切一下就好

MDView 有预览、编辑和分屏三种视图。预览适合专心读；编辑直接修改 Markdown；分屏则是左边写、右边看效果。同步滚动可以开启，也可以关闭：校对同一段时让两边一起走，对照不同位置时各自停着。

工具栏里有标题、粗体、斜体、引用、代码块，以及普通列表、编号列表和任务列表等入口。选中文字再点一下，就能完成常见格式修改；表格用网格选择行列数，先生成骨架，再填内容。

偶尔忘了图片或列表怎么写，也不用临时打开网页搜索。内置的 Markdown 语法参考按类别列出示例，可以复制后改成自己的内容。底部状态栏会显示保存状态、字数、字符数、预计阅读时间和光标位置，写着写着也能知道篇幅到哪里了。

![实机截图：分屏模式中同时显示 Markdown 源码和排版预览](assets/05-split-editing.jpg)

*实机截图：边改边看效果，同步滚动可以按需要开关。*

需要统一修改一个名称时，可以在编辑视图中查找替换，逐个替换或全部替换。熟悉的快捷键也能用：`Ctrl+S` 保存，`Ctrl+B` 加粗，`Ctrl+Z` 撤销；列表缩进用 `Tab`，退回来用 `Shift+Tab`。macOS 上相应的常用快捷键使用 `Command`。

## 插图和写公式，少忙几步

在桌面版编辑器里，图片可以粘贴、拖入，也可以批量选择插入。MDView 会把图片复制到文档旁边的 `assets` 文件夹，并写好相对路径；遇到同名图片会另取文件名。新文档会先让你选择保存位置，再放图片。

这对写图文笔记很实用：截一张图，粘进去，继续写。以后搬到另一个文件夹，把 Markdown 和旁边的 `assets` 一起带走就行。批量插图时有进度提示，失败的图片也能重试，不必整批重新来。

公式也有专门入口。点工具栏的 `Σ`，可以选择行内或独立公式，使用分数、根号、上下标、求和、积分、矩阵等常用模板。输入时会显示实时预览，写法不支持时也会提示，确认排版后再插入正文。

![实机截图：公式编辑器提供常用模板和实时排版预览](assets/06-math-editor.jpg)

*实机截图：常用公式有模板，输入时就能看到排版效果。*

## 文件在别处改了，这里也能跟上

有时我会让 AI 编程工具整理同一份文档，然后回到 MDView 阅读。桌面版会检测本地文件变化：当前没有未保存修改时，会载入磁盘上的新内容。

如果我也正在修改，应用会提示文件在外部发生了变化，让我选择保留当前编辑，还是重新载入磁盘版本。这个选择很有用，尤其是一边请 AI 改材料、一边自己补几句的时候。

未保存的修改还会在本机备份为草稿。下次启动发现可恢复的草稿，会让我选择恢复或丢弃。平时我依然习惯随手保存，有这层照应，临时中断后也多一个接着写的机会。

## Word 转进来，整理好的内容再带出去

手头已经有 Word 文件，可以把 `.docx` 导入成 Markdown 草稿，整理后再保存。转换在本机完成，原始 Word 文件保持不变。第一次需要准备 Python 和转换组件，导入窗口提供准备入口；下载组件需要联网，就绪后可以离线转换。

![实机截图：Word 导入窗口显示本地转换器状态和文档选择入口](assets/07-word-import.jpg)

*实机截图：先准备本地转换器，再把 Word 转成可整理的 Markdown 草稿。*

分享时，我会按对方接下来要做什么来选格式。

**对方还要继续修改，就导出 Word。** 导出的文档有真正的标题层级、列表和表格。中文正文用宋体，标题用黑体，正文带首行缩进，还有页眉和页码；代码块有单独的字体和底色，表格表头也有区分。拿去继续改报告，可以少做一轮基础排版。

公式也尽量保留后续修改的空间：能转换的会导出为 Word 可编辑公式，超出转换范围时尝试用图片保留外观，并提示处理结果。

**对方只要打开看，就导出独立 HTML。** 排版样式、可读取的图片和公式所需字体会放进文件里，Mermaid 也会按浅色重新渲染。读者用浏览器就能打开，不需要安装 MDView。准备导出时，应用会处理图表和图片；有图片没能嵌入，会提示你。

**需要定稿或打印，就选 PDF。** MDView 会准备阅读版排版，再打开系统打印窗口，选择保存为 PDF 即可。含 Mermaid 图表的材料，我通常会选 HTML 或 PDF；当前 Word 导出会把 Mermaid 保留为代码内容，不能当成相同的图形效果。

![实机截图：导出菜单提供 HTML、PDF 和 Word 文档选项](assets/08-export.jpg)

*实机截图：要继续修改、直接阅读，还是定稿打印，可以各选合适的格式。*

我希望 Markdown 能一直作为方便维护的原稿，而分享时不必要求每个收到文件的人都先学会 Markdown。

## 已经有 Typora 或 VS Code，还会用它吗？

我自己会按当天的事情来选。Typora 的实时预览很适合连续写作，它也有目录、公式、图表和导入导出；经常写长文章的人，可以看看这种边写边呈现的方式。[Typora 官方介绍](https://typora.io/)

VS Code 在项目里维护文档很顺手：有大纲、并排预览、双向滚动同步，也能预览公式和 Mermaid。已经在里面写代码、改项目说明时，继续用它就很自然。[VS Code Markdown 指南](https://code.visualstudio.com/Docs/languages/markdown)

MDView 是我给日常阅读准备的选择。收到一份方案，双击打开，调好字号和宽度，收起暂时不看的目录，复制一段代码，再把整理好的内容导出——这些小事，我想让它在同一个窗口里做得顺手。

| 当天主要想做什么 | 我会怎么选 |
| --- | --- |
| 连续写文章，喜欢在正文里边写边看到排版 | 看看 Typora 的实时预览写作方式 |
| 在代码项目中一起维护文档、查看修改 | 使用已有的 VS Code 工作环境 |
| 阅读一份本地 Markdown，偶尔改几处，再导出分享 | 打开 MDView，沿着阅读流程处理 |

这些工具都能帮助阅读 Markdown，具体怎么用，要看自己的习惯。我更在意 MDView 怎样安排一次普通阅读：读者先找到内容，再按自己的习惯看清楚，需要修改时也有入口。

## 下一份文档，打开试试

MDView 免费、开源、没有广告，也不需要注册。Windows 有安装版和绿色版，工程还提供 macOS 和 Edge 扩展的使用方式，具体安装说明可以看[项目 README](../../README.md)。本文实机截图来自 Windows 桌面版。

如果你手头刚好有一份 AI 生成的方案、项目说明或学习笔记，可以到 [MDView Releases](https://github.com/isunky/MDView/releases/latest) 看看适合自己的版本。

打开后，先点一个目录，调一下字号，再点开一张图片。很多小功能，读着读着就会用到了。
